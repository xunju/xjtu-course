# XJTU 课程 PPT 浏览器插件开发与验收计划

目标产品是一个可安装到 Edge/Chrome 的 Manifest V3 插件，加一个本机处理服务。插件负责课程页面识别、用户选择和进度展示；本机服务复用当前 Node/Python 处理链，负责授权媒体捕获、缓存、抽帧、OCR、页面版本聚类、PDF 导出和可选总结。

## 用户流程

### 课程列表入口

用户登录后打开：

`https://lms.xjtu.edu.cn/user/courses#/`

点击插件图标，插件扫描当前 DOM 中的课程卡片，显示课程名称、课程 ID 和课程链接。用户选择一门课程后，插件打开对应的：

`https://lms.xjtu.edu.cn/course/{courseId}/lesson#/`

插件保存课程选择，但不保存密码、Cookie 或签名媒体 URL。

### 整门课程入口

在课程课次页面点击插件，插件读取所有课次。分页必须逐页确认：每次点击页码后等待加载结束，并同时确认当前页码、课次 ID 集合和课次数量发生变化。只要页面仍显示上一页的首个课次，就禁止开始下载。

确认全部页面后，插件展示课次列表和勾选框。用户可以选择：

- 当前页全部课次；
- 全部页全部课次；
- 指定课次。

每个课次进入独立任务状态，成功审计后才允许删除临时视频。

### 单节视频入口

用户直接打开：

`https://lms.xjtu.edu.cn/course/{courseId}/learning-activity#/{lessonId}`

插件从 URL 解析课程 ID 和课次 ID，显示“生成本节 PDF”。该模式不扫描课程分页，也不处理其他课次。

## 系统结构

```text
MV3 插件
├── service_worker.js       任务、标签页和本地服务通信
├── content-lms.js          课程列表/课程页 DOM 读取、分页状态读取
├── content-player.js       播放器检测、播放触发、状态回报
├── popup/                  课程选择、课次选择、采样设置、进度
└── options/                本地服务地址和默认设置
        │ localhost HTTP 或 Native Messaging
        ▼
本地 Node 服务
├── 任务状态与断点恢复
├── CDP/媒体捕获和 XJTU 缓存
├── slide_scan.py + OCR
├── 页面版本/章节整理
├── PDF/JPG/JSON/Markdown 导出
└── course-audit 与安全清理
```

插件不能承担长视频解码和 OCR。媒体请求只在用户已登录并有权访问播放器时捕获；服务端只在内存中使用短期授权信息，输出文件不得包含 Cookie、Authorization 或签名查询参数。

## 采样设置

插件提供三个预设，并允许高级设置：

| 预设 | interval | threshold | versionVisual | versionText | slideVisual | slideText | 取舍 |
|---|---:|---:|---:|---:|---:|---:|---|
| 快速 | 1.0s | 0.03 | 0.999 | 0.98 | 0.999 | 0.99 | 速度快，短暂页面可能漏采 |
| 默认 | 0.3s | 0.03 | 0.999 | 0.98 | 0.999 | 0.99 | 推荐，兼顾速度和完整性 |
| 完整 | 0.1s | 0.03 | 0.999 | 0.98 | 0.999 | 0.99 | 扫描和 OCR 成本更高 |

固定项目默认值为默认预设。插件显示预计候选帧数、预计处理时间，并把实际参数写入任务状态和 `course.json`。

## 分页识别要求

分页是全流程的关键验收点。课程页扫描器必须：

1. 读取分页控件中的有效数字，不把课次编号或页脚数字当成页码；
2. 记录点击前的 `pageNumber`、首个课次 ID、课次 ID 集合和 DOM 快照哈希；
3. 点击目标页码或“下一页”；
4. 等待加载指示器消失，且目标页码具有 active/current 状态；
5. 等待首个课次 ID 与上一页不同，并确认新课次集合非空；
6. 对同一页重复读取三次，结果一致后才返回；
7. 用课次 ID 去重，防止异步刷新导致第一页课次被重复加入；
8. 页面确认失败时停止该课程任务，保留已完成课次和缓存，记录原因；
9. 处理完一页后重新读取总页数，不能假定每页固定 20 条；
10. 最后一页通过“无新课次 ID”或明确的 disabled 下一页判断结束。

## 任务状态

```json
{
  "courseId": "32342",
  "lessonId": "1291472",
  "page": 1,
  "status": "completed",
  "sampling": {
    "interval": 0.3,
    "threshold": 0.03,
    "versionVisual": 0.999,
    "versionText": 0.98,
    "slideVisual": 0.999,
    "slideText": 0.99
  },
  "output": ".../course.pdf",
  "slides": 129,
  "videoDeleted": true
}
```

状态值：`discovered`、`opening`、`capturing`、`downloading`、`processing`、`auditing`、`completed`、`failed`、`skipped`。重启后只恢复未完成任务；失败任务按配置重试，超过次数后暂停并保留缓存。

## 里程碑

### M1：插件壳和本地服务握手

- 安装未打包插件；
- 在课程列表页显示课程扫描按钮；
- 插件能检测当前页面类型；
- localhost 健康检查和版本协商通过。

### M2：课程列表和课程选择

- 扫描所有课程卡片；
- 过滤非课程链接；
- 选择课程后跳转课次页；
- 课程 ID、名称和 URL 状态可恢复。

### M3：分页课次扫描

- 第一页、第二页和最后一页识别正确；
- 异步刷新期间不会混入旧页课次；
- 总课次数与页面人工核对一致；
- 重复扫描结果稳定。

### M4：单节 PDF

- 从单节视频页识别 lesson ID；
- 捕获 PPT 轨道并生成 PDF；
- `course-audit` 通过；
- 失败时不删除缓存，成功时按开关删除。

### M5：整门课程批处理

- 用户可勾选部分或全部课次；
- 逐课处理、状态持久化、失败重试和断点恢复；
- 合并已审计课次 PDF；
- 分页和播放器错误都能在界面定位到课次。

### M6：采样预设和高级参数

- 快速、默认、完整预设可切换；
- 高级设置校验范围；
- 任务中记录实际参数；
- 同一视频用不同参数生成不同任务目录，不能复用错误缓存。

### M7：浏览器分发与安装验收

- Edge 开发者模式加载目录成功；
- Chrome 开发者模式加载目录成功；
- 权限说明与实际 host permissions 一致；
- 插件升级不丢失任务状态；
- 不包含真实课程视频、Cookie、Authorization 或 API Key。

## 软件级验收矩阵

| 编号 | 场景 | 通过条件 |
|---|---|---|
| A01 | 未登录课程列表 | 插件显示需要登录，不发起媒体捕获 |
| A02 | 已登录课程列表 | 课程数量、名称、ID 与页面一致 |
| A03 | 课程页第一页 | 课次 ID、标题、时间与页面一致 |
| A04 | 课程页切换第二页 | 页码 active、首个课次 ID、集合均确认变化 |
| A05 | 异步加载延迟 | 超时后任务暂停，不处理旧页、不误删视频 |
| A06 | 分页重复点击 | 课次 ID 去重，任务数量稳定 |
| A07 | 单节页面 | 只生成当前 lesson PDF |
| A08 | 单课捕获失败 | 状态 failed，视频缓存保留，可重试 |
| A09 | 单课成功 | PDF/JPG/JSON/Markdown 存在，audit 通过 |
| A10 | 删除开关关闭 | 成功后视频仍保留 |
| A11 | 删除开关开启 | 仅 audit 成功后删除对应课次缓存 |
| A12 | 处理进程中断 | 重启后从状态文件恢复，不重复完成课次 |
| A13 | 0.3 秒默认采样 | 参数完整写入状态和输出 |
| A14 | 不同采样预设 | 输出目录和缓存键隔离 |
| A15 | 最终合并 PDF | 只包含已审计课次，顺序正确，页数可核对 |
| A16 | 隐私检查 | 输出和日志不含 Cookie、Authorization、签名 URL、API Key |
| A17 | Edge 安装 | 开发者模式加载、页面按钮和任务进度正常 |
| A18 | Chrome 安装 | 同上，且无 Edge 专属 API 依赖 |

## 发布门槛

发布前必须同时满足：

- 单元和集成测试通过；
- 分页模拟测试覆盖第一页、中间页、最后一页、空页和异步超时；
- 单节真实 LMS 流程成功；
- 至少一门课程的全部课次成功或明确记录失败原因；
- 合并 PDF 通过渲染抽检；
- 清理和隐私审计通过；
- 插件目录可在 Edge 和 Chrome 开发者模式加载。
